# Flashcards

Flashcards help you remember the words of each chapter. Read the word on the front, say its meaning aloud, then click the card to turn it over and check.

| Chapter | Cards to click | Download for Anki or Quizlet |
|---|---|---|
| 1 Computer System Organisation | [50 flashcards](../unit-1/001-ch01-computer-system-organisation/flashcards.md) | [ch01.csv](ch01.csv) |
| 3 Boolean Logic and Logic Circuits | [32 flashcards](../unit-1/003-ch03-boolean-logic/flashcards.md) | [ch03.csv](ch03.csv) |

The cards of the other chapters will be added here as each chapter is written.

**Using the download.** Each CSV file has two columns, front and back. In Anki: *File → Import*, choose the file, and set the separator to comma. In Quizlet: *Create → Import*, and paste the file's text.
