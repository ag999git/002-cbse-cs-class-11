# How to use this site

1. **Scan the QR code** beside a topic in the book: it opens the page for that topic.
2. **Each chapter has a home page** (the QR code at the start of the chapter) listing all its pages.
3. **Questions** are for learning, not testing: read the question, try it, then read the answer and the reason below it.
4. **The grey tag line** under a question shows its type · difficulty (E, M, H) · how often it is asked (★★★ to ☆) · priority (A, B, C).
