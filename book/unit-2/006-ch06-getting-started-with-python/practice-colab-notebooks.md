## How to use them

1. Open a notebook; run the first cell with **Shift + Enter**.
2. **Predict first:** before running a cell marked *My prediction*, write what you expect.
3. **Modify:** change the cell and run it again; nothing can break.
4. In notebook 6-4, type your answers where it says `None` and run each check.

*Remember the Colab trap: a cell shows the value of its last line by itself, a script does not. In IDLE, use `print`.*
