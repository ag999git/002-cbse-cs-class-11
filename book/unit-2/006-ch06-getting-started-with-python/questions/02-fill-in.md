# Chapter 6: Getting Started with Python: Fill in the blanks (35)

*Chapter 6 · Questions (online). One mark each. Try each one first. The difficulty (E easy, M medium, H hard) and the section of the book are given in brackets. Every output and error message on this page was made by running Python 3.12.7 (`tools/ch06_typed_questions.py`).*

## Fill in the blanks

**Q1.** Python was first released in ______. *(E · 6.1)*

**Answer.** 1991 (version 0.9.0, February 1991).

**Q2.** Python's name comes from the British TV show ______. *(E · 6.1)*

**Answer.** *Monty Python's Flying Circus*.

**Q3.** A program that translates and runs one statement at a time is an ______. *(E · 6.1)*

**Answer.** interpreter.

**Q4.** IDE stands for ______. *(E · 6.2)*

**Answer.** Integrated Development Environment.

**Q5.** IDLE's window for interactive mode is the ______. *(E · 6.2)*

**Answer.** shell.

**Q6.** In Google Colab, your code runs on ______ computers. *(E · 6.2)*

**Answer.** Google's (the cloud).

**Q7.** A Jupyter or Colab notebook is made of ______. *(E · 6.2)*

**Answer.** cells.

**Q8.** In a script, a value is shown on the screen only by ______. *(E · 6.3)*

**Answer.** `print()`.

**Q9.** The IDLE menu command that runs a script is Run → ______. *(E · 6.3)*

**Answer.** Run Module.

**Q10.** The keyboard shortcut to save a file in IDLE is ______. *(E · 6.3)*

**Answer.** Ctrl+S.

**Q11.** The ______ line of an error message names the error and its cause. *(E · 6.3)*

**Answer.** last.

**Q12.** The set of characters that Python accepts is its ______. *(E · 6.4)*

**Answer.** character set.

**Q13.** The five kinds of token are keyword, identifier, literal, operator and ______. *(E · 6.4)*

**Answer.** punctuator.

**Q14.** A word that Python reserves for its own use is a ______. *(E · 6.5)*

**Answer.** keyword.

**Q15.** A name chosen by the programmer is an ______. *(E · 6.5)*

**Answer.** identifier.

**Q16.** The keywords `async` and `await` were added in Python ______. *(M · 6.5)*

**Answer.** 3.7 (2018).

**Q17.** An identifier must not begin with a ______. *(E · 6.5)*

**Answer.** digit.

**Q18.** The only special character allowed in an identifier is ______. *(E · 6.5)*

**Answer.** `_` (the underscore).

**Q19.** In snake_case, words are joined by ______. *(E · 6.5)*

**Answer.** `_`: for example `bus_fare`.

**Q20.** Java and JavaScript name variables in ______ style, like `rollNo`. *(M · 6.5)*

**Answer.** camelCase.

**Q21.** The value of the literal `2.5e3` is ______. *(M · 6.6)*

**Answer.** 2500.0 (2.5 × 10³).

**Q22.** The value of the literal `0b101` is ______. *(M · 6.6)*

**Answer.** 5 (binary 101).

**Q23.** The special literal that means "no value" is ______. *(E · 6.6)*

**Answer.** `None`.

**Q24.** A symbol or word that does work on values is an ______. *(E · 6.6)*

**Answer.** operator.

**Q25.** A value that an operator works on is an ______. *(E · 6.6)*

**Answer.** operand.

**Q26.** The name on the left of `=` is the ______. *(E · 6.7)*

**Answer.** L-value.

**Q27.** `id()` gives an object's ______. *(M · 6.7)*

**Answer.** identity number (unique while the object exists).

**Q28.** `type(x)` gives the type of the ______ that `x` is tied to. *(M · 6.7)*

**Answer.** object.

**Q29.** Tying one name to values of different types at different times is called ______ typing. *(E · 6.7)*

**Answer.** dynamic.

**Q30.** In C++ and Java a variable's type is fixed before the program runs: ______ typing. *(M · 6.7)*

**Answer.** static.

**Q31.** After `x, y = 5, 7` and then `x, y = y, x`, the value of `x` is ______. *(M · 6.7)*

**Answer.** 7.

**Q32.** A comment written after a statement on the same line is an ______ comment. *(E · 6.8)*

**Answer.** inline.

**Q33.** A triple-quoted note as the first statement of a program is called a ______. *(M · 6.8)*

**Answer.** docstring.

**Q34.** `print(len("ab\ncd"))` prints ______. *(H · 6.6)*

**Answer.** 5: `\n` is one character.

**Q35.** PEP stands for Python ______ Proposal. *(E · 6.5)*

**Answer.** Enhancement.
