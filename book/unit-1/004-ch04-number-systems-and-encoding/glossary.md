# Chapter 4: glossary

Every word explained in the chapter, in alphabetical order, with the section of the book where it is explained.

- **ASCII**: American Standard Code for Information Interchange: a 7-bit code for 128 English characters (4.5).
- **Base**: the number of digits a number system has; also called radix (4.1).
- **Binary**: the base-2 system, digits 0 and 1 (4.1).
- **Binary point**: the point in a binary number that separates the whole part from the fraction (4.2).
- **Character**: one letter, digit, sign or symbol (4.5).
- **Character set**: the list of characters a scheme can write (4.5).
- **Code**: the fixed number given to a character (4.1).
- **Code point**: the number Unicode gives a character, written U+ and hex (4.5).
- **Control code**: an ASCII code that prints nothing, such as 10 (new line) (4.5).
- **Conversion**: writing the same number in another system (4.3).
- **Decimal**: the base-10 system, digits 0 to 9 (4.1).
- **Digit**: one symbol used to write numbers (4.1).
- **Encoding scheme**: a table giving every character a fixed number that everyone uses (4.5).
- **Extended ASCII**: 8-bit versions of ASCII with 128 more codes, different from maker to maker (4.5).
- **Fixed-length encoding**: every character takes the same number of bytes (UTF-32) (4.5).
- **Fraction part**: the digits after the point (4.4).
- **Grouping**: cutting a binary number into groups of 3 or 4 bits (4.3).
- **Hexadecimal**: the base-16 system, digits 0 to 9 and A to F (4.1).
- **ISCII**: Indian Script Code for Information Interchange: an 8-bit code for Indian scripts (4.5).
- **LSB**: least significant bit, the bit with the smallest place value (4.2).
- **MSB**: most significant bit, the bit with the largest place value (4.2).
- **Number system**: a way of writing numbers with a fixed set of digits (4.1).
- **Octal**: the base-8 system, digits 0 to 7 (4.1).
- **Padding**: adding 0s at the far end of a number to fill the last group (4.3).
- **Place value**: what a digit is worth because of its place; also positional value or weight (4.2).
- **Position**: the number of a place, 0, 1, 2 … leftwards from the point (4.2).
- **Repeating fraction**: a fraction whose digits repeat for ever (4.4).
- **Unicode**: one standard giving a code point to every character of every language (4.5).
- **UTF-8**: stores a code point in 1 to 4 bytes (variable length) (4.5).
- **UTF-32**: stores every code point in 4 bytes (fixed length) (4.5).
- **Variable-length encoding**: characters take different numbers of bytes (UTF-8) (4.5).
