# Chapter 3: Boolean Logic and Logic Circuits: Fill in the blanks (25)

*Chapter 3 · Questions (online). The questions of the printed chapter and many more, each followed by its answer and the reason. Try each one first. The difficulty (E easy, M medium, H hard) and the section of the book are given in brackets. Every Boolean answer on this page was checked by a program (`tools/ch03_typed_questions.py`).*

**Q1.** The operation done by a NOT gate is called ______. *(E · 3.2)*

**Answer.** complementation (inversion).

**Q2.** The NOT gate is also called an ______. *(E · 3.2)*

**Answer.** inverter.

**Q3.** An OR gate gives 0 only when all its inputs are ______. *(E · 3.2)*

**Answer.** 0.

**Q4.** An AND gate gives 1 only when all its inputs are ______. *(E · 3.2)*

**Answer.** 1.

**Q5.** A NOR gate is an OR gate followed by a ______ gate. *(E · 3.3)*

**Answer.** NOT.

**Q6.** The two universal gates are ______ and ______. *(E · 3.3)*

**Answer.** NAND and NOR.

**Q7.** The XOR gate is also called the ______ OR gate. *(E · 3.4)*

**Answer.** exclusive.

**Q8.** The XOR gate gives 1 when an ______ number of inputs are 1. *(M · 3.5)*

**Answer.** odd.

**Q9.** A 2-input XNOR gate gives 1 when its inputs are ______. *(E · 3.4)*

**Answer.** the same (both 0 or both 1).

**Q10.** Switches joined one after the other are in ______, and they make an ______ gate. *(E · 3.4)*

**Answer.** series; AND.

**Q11.** A truth table of n inputs has ______ rows. *(E · 3.1)*

**Answer.** 2ⁿ.

**Q12.** A truth table with 5 inputs has ______ rows. *(E · 3.1)*

**Answer.** 32 (2⁵).

**Q13.** The inputs of a 3-input truth table run from 000 to ______. *(E · 3.1)*

**Answer.** 111 (0 to 7 in binary).

**Q14.** In Boolean algebra, + stands for ______ and · stands for ______. *(E · 3.1)*

**Answer.** OR; AND.

**Q15.** A · A = ______ (idempotent law). *(E · 3.7)*

**Answer.** A.

**Q16.** A · 0 = ______ (null law). *(E · 3.7)*

**Answer.** 0.

**Q17.** A + 0 = ______ (identity law). *(E · 3.7)*

**Answer.** A.

**Q18.** A + A·B = ______ (absorption law). *(E · 3.7)*

**Answer.** A.

**Q19.** A + A'·B = ______. *(M · 3.7)*

**Answer.** A + B (redundant-literal law).

**Q20.** De Morgan's first law: (A + B)' = ______. *(E · 3.6)*

**Answer.** A' · B'.

**Q21.** De Morgan's second law: (A · B)' = ______. *(E · 3.6)*

**Answer.** A' + B'.

**Q22.** The dual of A + 0 = A is ______. *(E · 3.7)*

**Answer.** A · 1 = A.

**Q23.** An expression that is 1 for every combination of inputs is a ______. *(E · 3.7)*

**Answer.** tautology.

**Q24.** An expression that is 0 in every row is a ______. *(E · 3.7)*

**Answer.** fallacy.

**Q25.** In 1938 ______ applied Boolean algebra to switching circuits. *(E · 3.4)*

**Answer.** Claude Shannon.
