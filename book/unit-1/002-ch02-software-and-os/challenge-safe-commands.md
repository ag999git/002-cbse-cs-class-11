# Challenge: Ten safe commands to try

*Chapter 2 · Challenge. The command-line interface (CUI) of section 2.6, tried for real. These ten commands only **show** information: they change nothing.*

**How to open the command line:** on Windows, press the Windows key, type **cmd** and press Enter. On Linux
(or a Chromebook's Linux terminal, or a Raspberry Pi), open **Terminal**.

| What it does | Windows (cmd) | Linux |
|---|---|---|
| See the files in this folder | `dir` | `ls` |
| Show which folder you are in | `cd` | `pwd` |
| Show your user name | `whoami` | `whoami` |
| Show the date | `date /t` | `date` |
| Show the computer's name | `hostname` | `hostname` |
| Print a message | `echo Namaste` | `echo Namaste` |
| Show the OS version | `ver` | `uname -a` |
| Show the folders as a tree | `tree` | `ls -R` |
| Show the network address | `ipconfig` | `ip addr` |
| Clear the screen | `cls` | `clear` |

## Three rules

1. **Never type a command you do not understand**, and never paste one sent by a stranger: a single line can delete
   files or install malware.
2. Commands that **delete or format** (`del`, `rd`, `format`; `rm`) are not for practice.
3. Try them at school with your teacher, or on your own computer.

**Challenge:** which command would you use to find out which folder you are in, and which to see what is in it? Why does
a programmer find this faster than clicking?
