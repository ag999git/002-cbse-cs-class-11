# Chapter 2: glossary

Every word explained in the chapter, in alphabetical order, with the section of the book where it is explained.

- **Application software**: software that does a job for the user (2.3).
- **Assembler**: turns assembly into machine code (2.4).
- **Assembly language**: short codes for machine instructions (2.4).
- **Compiler**: translates the whole program into object code (2.4).
- **Customised software**: made for one user's needs (2.3).
- **Device driver**: lets the OS work one device (2.2).
- **GUI**: graphical user interface (2.6).
- **High-level language**: English-like programming language (2.4).
- **IDE**: editor, translator and error messages in one window (2.4).
- **Interpreter**: translates and runs one statement at a time (2.4).
- **Machine language**: instructions as 0s and 1s (2.4).
- **Memory management**: giving RAM to programs and taking it back (2.5).
- **Object code**: a program in machine language (2.4).
- **Operating system**: the software that runs the computer (2.2).
- **Process**: a running program (2.5).
- **Resource manager**: the OS, sharing CPU, memory, files, devices (2.5).
- **Source code**: a program as written (2.4).
- **System software**: software that runs the computer (2.1).
- **User interface**: how the user gives commands (2.6).
- **Utility**: a program that keeps the computer healthy (2.2).
