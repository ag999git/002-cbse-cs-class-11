## Multiple-choice questions

**Q1.** Which software makes the hardware useful? (a) firmware only (b) software (c) cables (d) a monitor *(E · 2.1)*

**Answer.** (b) software. *Why:* software tells the hardware what to do.

**Q2.** A washing machine does a Cotton or a Quick wash because of its: (a) motor (b) drum (c) program (d) pump *(E · 2.1)*

**Answer.** (c) program. *Why:* the parts are the same; only the program changes.

**Q3.** How many groups of software does the syllabus name? (a) two (b) three (c) four (d) five *(E · 2.1)*

**Answer.** (b) three. *Why:* system; programming tools and translators; application.

**Q4.** Which is the most basic software? (a) a browser (b) the operating system (c) a game (d) a driver *(E · 2.2)*

**Answer.** (b) the operating system. *Why:* no other program runs without it.

**Q5.** BOSS Linux was developed by: (a) ISRO (b) C-DAC (c) IIT Bombay (d) NIC *(M · 2.2)*

**Answer.** (b) C-DAC. *Why:* C-DAC made this Indian Linux.

**Q6.** Which utility is NOT needed on a phone? (a) backup (b) antivirus (c) defragmenter (d) cleanup *(M · 2.2)*

**Answer.** (c) defragmenter. *Why:* phones use flash memory, with no moving parts.

**Q7.** A device driver is needed because: (a) the OS cannot know every device's own signals (b) devices have no power (c) it is an antivirus (d) it speeds up the CPU *(M · 2.2)*

**Answer.** (a) the OS cannot know every device's own signals. *Why:* each model needs its own exact signals.

**Q8.** The universal remote in the book stands for: (a) the operating system (b) a device driver (c) a compiler (d) a utility *(H · 2.2)*

**Answer.** (a) the operating system. *Why:* the remote is the OS; each brand's code set is a driver.

**Q9.** Customised software is made for: (a) everyone (b) one organisation's needs (c) games only (d) the OS *(E · 2.3)*

**Answer.** (b) one organisation's needs. *Why:* like a jersey printed with your name.

**Q10.** Which can a computer work without? (a) the OS (b) application software (c) drivers (d) system software *(E · 2.3)*

**Answer.** (b) application software. *Why:* it cannot work without system software.

**Q11.** Machine language is written in: (a) English (b) short codes (c) 0s and 1s (d) Python *(E · 2.4)*

**Answer.** (c) 0s and 1s. *Why:* the CPU understands only 0s and 1s.

**Q12.** ADD, LOAD and STORE are: (a) machine code (b) assembly codes (c) Python keywords (d) OS commands *(E · 2.4)*

**Answer.** (b) assembly codes. *Why:* short codes for machine instructions.

**Q13.** A program written by the programmer is: (a) object code (b) source code (c) machine code (d) bytecode *(E · 2.4)*

**Answer.** (b) source code. *Why:* object code is the translated version.

**Q14.** Which translator makes a file that runs without it? (a) assembler only (b) interpreter (c) compiler (d) editor *(E · 2.4)*

**Answer.** (c) compiler. *Why:* the compiler makes an object-code file.

**Q15.** An interpreter meets an error in line 6 of 9. How many lines have run? (a) 0 (b) 5 (c) 6 (d) 9 *(M · 2.4)*

**Answer.** (b) 5. *Why:* lines 1 to 5 ran; it stops at 6.

**Q16.** A compiler meets errors in lines 2 and 8. How many lines run? (a) 0 (b) 1 (c) 2 (d) 7 *(M · 2.4)*

**Answer.** (a) 0. *Why:* nothing runs until every error is fixed.

**Q17.** Which translator stays in memory while the program runs? (a) compiler (b) interpreter (c) assembler (d) linker *(M · 2.4)*

**Answer.** (b) interpreter. *Why:* it translates each statement as it runs.

**Q18.** Python first turns a program into: (a) machine code (b) bytecode (c) assembly (d) HTML *(H · 2.4)*

**Answer.** (b) bytecode. *Why:* then it runs the bytecode (Beyond syllabus page).

**Q19.** IDE stands for: (a) Internal Device Engine (b) Integrated Development Environment (c) Input Data Editor (d) Interpreted Data Entry *(E · 2.4)*

**Answer.** (b) Integrated Development Environment. *Why:* editor, translator and errors in one window.

**Q20.** The OS is called a resource manager because it: (a) manages money (b) shares the CPU, memory, files and devices (c) repairs hardware (d) writes programs *(E · 2.5)*

**Answer.** (b) shares the CPU, memory, files and devices. *Why:* it decides who gets what.

**Q21.** A running program is a: (a) file (b) process (c) driver (d) folder *(E · 2.5)*

**Answer.** (b) process. *Why:* a program on storage becomes a process when it runs.

**Q22.** Giving RAM to a program and taking it back is: (a) process (b) memory (c) file (d) device *(E · 2.5)*

**Answer.** (b) memory. *Why:* memory management.

**Q23.** App permissions are part of: (a) file management (b) security (c) device management (d) the user interface *(M · 2.5)*

**Answer.** (b) security. *Why:* they decide what an app may use.

**Q24.** In the airport analogy, the runway is the: (a) RAM (b) CPU (c) hard disk (d) printer *(E · 2.5)*

**Answer.** (b) CPU. *Why:* one plane at a time = one program at a time.

**Q25.** A phone with 8 cores is like an airport with: (a) 8 gates (b) 8 runways (c) 8 towers (d) 8 counters *(M · 2.5)*

**Answer.** (b) 8 runways. *Why:* 8 programs can really run at the same instant.

**Q26.** Which interface needs commands to be remembered? (a) GUI (b) touch (c) command (CUI) (d) voice *(E · 2.6)*

**Answer.** (c) command (CUI). *Why:* commands must be typed exactly.

**Q27.** Pinching to zoom is: (a) gesture (b) touch (c) voice (d) GUI *(M · 2.6)*

**Answer.** (b) touch. *Why:* it is done on the touchscreen.

**Q28.** Which interface helps a person who cannot see? (a) touch only (b) voice (c) GUI (d) gesture *(E · 2.6)*

**Answer.** (b) voice. *Why:* speaking and listening need no sight.

**Q29.** Which is malware that pretends to be useful? (a) virus (b) trojan (c) adware (d) utility *(M · 2.2)*

**Answer.** (b) trojan. *Why:* like the Trojan horse; Chapter 18.

**Q30.** The best defence against ransomware is: (a) a faster CPU (b) a recent backup (c) a bigger screen (d) a new driver *(M · 2.2)*

**Answer.** (b) a recent backup. *Why:* restore the files and pay nobody.

**Q31.** Which is system software? (a) Google Chrome (b) a photo editor (c) macOS (d) a code editor *(E · 2.1)*

**Answer.** (c) macOS. *Why:* it runs a Mac.

**Q32.** Which is application software? (a) a photo editor (b) an assembler (c) a code editor (d) Android *(E · 2.1)*

**Answer.** (a) a photo editor. *Why:* it edits pictures.

**Q33.** Which is a language translator or programming tool? (a) IDLE (b) Linux (Ubuntu) (c) a graphics-card driver (d) disk cleanup *(E · 2.1)*

**Answer.** (a) IDLE. *Why:* it is the editor and error window for Python.

**Q34.** Which is system software? (a) Windows 11 (b) a hospital's patient system (c) a photo editor (d) IDLE *(E · 2.1)*

**Answer.** (a) Windows 11. *Why:* it runs the whole computer.

**Q35.** Which is application software? (a) WhatsApp (b) a graphics-card driver (c) Android (d) BOSS Linux *(E · 2.1)*

**Answer.** (a) WhatsApp. *Why:* it does a job for the user: messages.

**Q36.** Which is a language translator or programming tool? (a) a code editor (b) an antivirus (c) iOS (d) VLC media player *(E · 2.1)*

**Answer.** (a) a code editor. *Why:* it is used to type source code.

**Q37.** Which is system software? (a) MS Excel (b) macOS (c) IRCTC (d) IDLE *(E · 2.1)*

**Answer.** (b) macOS. *Why:* it runs a Mac.

**Q38.** Which is application software? (a) a printer driver (b) a company's payroll system (c) a C++ compiler (d) disk cleanup *(E · 2.1)*

**Answer.** (b) a company's payroll system. *Why:* it was made for one company's salaries.

**Q39.** Which is a language translator or programming tool? (a) macOS (b) an assembler (c) an antivirus (d) a graphics-card driver *(E · 2.1)*

**Answer.** (b) an assembler. *Why:* it translates assembly language into machine code.

**Q40.** Which is system software? (a) WhatsApp (b) a hospital's patient system (c) a company's payroll system (d) a webcam driver *(E · 2.1)*

**Answer.** (d) a webcam driver. *Why:* it lets the OS work the webcam.
