## True or false

**Q1.** Hardware can do useful work without software. *(E · 2.1)*

**Answer.** False. *Why:* it needs programs to tell it what to do.

**Q2.** The syllabus puts translators in their own group. *(E · 2.1)*

**Answer.** True. *Why:* "programming tools and language translators".

**Q3.** An antivirus is application software. *(E · 2.2)*

**Answer.** False. *Why:* it is a utility, a kind of system software.

**Q4.** Utilities can come with the OS. *(E · 2.2)*

**Answer.** True. *Why:* disk cleanup and backup usually do.

**Q5.** A defragmenter speeds up an SSD. *(E · 2.2)*

**Answer.** False. *Why:* an SSD has no moving parts.

**Q6.** Every device of the same kind uses exactly the same driver. *(E · 2.2)*

**Answer.** False. *Why:* each model may need its own.

**Q7.** Drivers should be downloaded only from the maker's website. *(E · 2.2)*

**Answer.** True. *Why:* fake driver pop-ups carry trojans.

**Q8.** WhatsApp is system software. *(E · 2.3)*

**Answer.** False. *Why:* it does a job for the user.

**Q9.** DigiLocker is customised software. *(E · 2.3)*

**Answer.** True. *Why:* it was made for government documents.

**Q10.** A computer can run without an OS. *(E · 2.3)*

**Answer.** False. *Why:* nothing else can run without it.

**Q11.** Machine language is easy for people to write. *(E · 2.4)*

**Answer.** False. *Why:* long strings of 0s and 1s.

**Q12.** Assembly language is a high-level language. *(E · 2.4)*

**Answer.** False. *Why:* it is low-level: one code per machine instruction.

**Q13.** A high-level program can run on different kinds of CPU after translation. *(E · 2.4)*

**Answer.** True. *Why:* it is translated for each.

**Q14.** A compiler lists all errors at once. *(E · 2.4)*

**Answer.** True. *Why:* it reads the whole program first.

**Q15.** An interpreter makes an object-code file. *(E · 2.4)*

**Answer.** False. *Why:* a compiler does.

**Q16.** A compiled program runs faster. *(E · 2.4)*

**Answer.** True. *Why:* it is already translated.

**Q17.** An interpreter finds a division by 0 before running. *(E · 2.4)*

**Answer.** False. *Why:* it is found only while running.

**Q18.** A compiler can find a logical error. *(E · 2.4)*

**Answer.** False. *Why:* no translator finds a wrong formula.

**Q19.** IDLE comes with Python. *(E · 2.4)*

**Answer.** True. *Why:* it is installed with Python.

**Q20.** A process is a program that is running. *(E · 2.5)*

**Answer.** True. *Why:* on storage it is only a file.

**Q21.** The OS shares the CPU in turns. *(E · 2.5)*

**Answer.** True. *Why:* process management.

**Q22.** Memory management gives RAM and takes it back. *(E · 2.5)*

**Answer.** True. *Why:* when programs start and end.

**Q23.** The home screen is the whole OS. *(E · 2.5)*

**Answer.** False. *Why:* it is only the user interface.

**Q24.** A phone has only one CPU core. *(E · 2.5)*

**Answer.** False. *Why:* many phones have 8.

**Q25.** A GUI needs more memory than a CUI. *(E · 2.6)*

**Answer.** True. *Why:* pictures and windows need memory.

**Q26.** Voice interfaces help people who cannot see. *(E · 2.6)*

**Answer.** True. *Why:* they need no screen.

**Q27.** Gesture interfaces are found only in games. *(E · 2.6)*

**Answer.** False. *Why:* flip to silence, wave to skip.

**Q28.** A "digital arrest" is allowed by Indian law. *(E · 2.5)*

**Answer.** False. *Why:* there is no such thing; it is a fraud.

**Q29.** 1930 is the helpline when money has been lost to cyber fraud. *(E · 2.5)*

**Answer.** True. *Why:* call at once.

**Q30.** Letting others use your bank account for a fee is harmless. *(E · 2.5)*

**Answer.** False. *Why:* it makes you a money mule, a crime.
