## More questions

**Q1.** Name the two primary services an OS gives to make a computer usable. (NCERT style) *(M · 2.2–2.5)*

**Answer.** Managing the CPU (running programs) and managing memory; it also gives the user an interface.

**Q2.** How does a computer understand a program written in a high-level language? (NCERT style) *(M · 2.2–2.5)*

**Answer.** A translator (compiler or interpreter) turns it into machine language, which the CPU runs.

**Q3.** Can a computer have RAM but no secondary storage and still have software installed? (NCERT style) *(M · 2.2–2.5)*

**Answer.** Software could be loaded into RAM, but it is lost when the power goes off; installing needs secondary storage.

**Q4.** Why is system software needed even when no application is open? *(M · 2.2–2.5)*

**Answer.** It keeps running the hardware, devices, memory and security, and waits for the user.

**Q5.** What is a software library? Name three Python libraries in the syllabus. *(M · 2.2–2.5)*

**Answer.** Ready-made tested code; math, random, statistics (Chapter 15).

**Q6.** Give two advantages of using a library. *(M · 2.2–2.5)*

**Answer.** Saves writing code again; tested code has fewer bugs.

**Q7.** What is a real-time OS? Give an example. *(M · 2.2–2.5)*

**Answer.** One that must answer within a fixed short time every time; a car's airbag controller.

**Q8.** What is a multi-user OS? Give an example. *(M · 2.2–2.5)*

**Answer.** Many users share one computer through their own accounts; a railway reservation server.

**Q9.** What is the difference between a batch OS and a time-sharing OS? *(M · 2.2–2.5)*

**Answer.** Batch runs collected jobs without the user waiting; time-sharing gives many users short turns so each seems alone.

**Q10.** What is an embedded OS? Give an example from Chapter 2. *(M · 2.2–2.5)*

**Answer.** A small OS inside a machine that does one job; the washing machine of section 2.1.
