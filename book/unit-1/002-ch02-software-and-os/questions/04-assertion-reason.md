## Assertion and reason

**Q1.** A: The OS is system software. R: It manages the hardware and runs other programs. *(M · 2.2–2.6)*

**Answer.** (a).

**Q2.** A: A printer needs a driver. R: The OS does not know every printer's own signals. *(M · 2.2–2.6)*

**Answer.** (a).

**Q3.** A: An antivirus is a utility. R: It does a job such as writing letters. *(M · 2.2–2.6)*

**Answer.** (c). *Why:* R is false: it protects the computer.

**Q4.** A: Customised software suits one organisation. R: It is made for that organisation's needs. *(M · 2.2–2.6)*

**Answer.** (a).

**Q5.** A: Python runs line by line. R: Python uses an interpreter. *(M · 2.2–2.6)*

**Answer.** (a).

**Q6.** A: A compiled program runs faster. R: A compiler stays in memory while it runs. *(M · 2.2–2.6)*

**Answer.** (c). *Why:* R is false: the compiler is not needed then.

**Q7.** A: An interpreter stops at the first error. R: It runs each statement before reading the next. *(M · 2.2–2.6)*

**Answer.** (a).

**Q8.** A: Assembly language is easy for beginners. R: It uses short codes. *(M · 2.2–2.6)*

**Answer.** (d). *Why:* A is false: it is close to the machine and hard.

**Q9.** A: High-level languages need translators. R: The CPU understands only machine language. *(M · 2.2–2.6)*

**Answer.** (a).

**Q10.** A: Machine language needs no translator. R: It is written in 0s and 1s. *(M · 2.2–2.6)*

**Answer.** (a).

**Q11.** A: The OS is a resource manager. R: It shares the CPU, memory, files and devices. *(M · 2.2–2.6)*

**Answer.** (a).

**Q12.** A: Many apps seem to run at once. R: The CPU switches between them very fast. *(M · 2.2–2.6)*

**Answer.** (a).

**Q13.** A: A GUI is easy for beginners. R: A GUI uses little memory. *(M · 2.2–2.6)*

**Answer.** (c). *Why:* R is false: a GUI needs more memory.

**Q14.** A: A backup protects against ransomware. R: Ransomware locks your files. *(M · 2.2–2.6)*

**Answer.** (a).

**Q15.** A: A defragmenter helps a hard disk. R: An SSD has moving parts. *(M · 2.2–2.6)*

**Answer.** (c). *Why:* R is false: an SSD has none.
