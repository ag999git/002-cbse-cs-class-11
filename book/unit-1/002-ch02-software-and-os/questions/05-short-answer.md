# Chapter 2: Software and Operating Systems: Short-answer questions (30)

*Chapter 2 · Questions (online). Two or three marks each. Try each one first. The difficulty (E easy, M medium, H hard) and the section of the book are given in brackets. The answers of the generated pages come from checked tables in a program (`tools/ch02_typed_questions.py`).*

## Short answers

**Q1.** [2] Why is software needed? Use the washing machine. *(E · 2.1)*

**Answer.** Hardware cannot decide what to do; the program (Cotton, Quick wash) tells the same parts what to do and when.

**Q2.** [2] Name the three groups of software with one example each. *(E · 2.1)*

**Answer.** System (Windows); programming tools and translators (a compiler); application (WhatsApp).

**Q3.** [2] Why do some books put a compiler under system software? *(E · 2.1)*

**Answer.** It is not a job of the user; the syllabus gives translators a group of their own.

**Q4.** [2] Give two functions of utility software. *(E · 2.2)*

**Answer.** Protect the computer (antivirus); keep safe copies (backup).

**Q5.** [2] Why can the OS not work a new printer without its driver? *(E · 2.2)*

**Answer.** It knows "print a page" but not that model's own signals; the driver knows them.

**Q6.** [2] Name two operating systems for computers and two for phones. *(E · 2.2)*

**Answer.** Windows, Linux; Android, iOS.

**Q7.** [2] What is malware? Name its three kinds in the syllabus. *(E · 2.2)*

**Answer.** Harmful software: virus, trojan, adware.

**Q8.** [2] Give two safe habits about drivers and apps. *(E · 2.2)*

**Answer.** Drivers only from the maker's site; apps only from the official store.

**Q9.** [2] Differentiate general-purpose and customised software with examples. *(E · 2.3)*

**Answer.** Ready-made for anyone (a spreadsheet) vs made for one organisation (a school's fee app).

**Q10.** [2] Name two general-purpose and two customised applications. *(E · 2.3)*

**Answer.** Word processor, browser; payroll system, IRCTC.

**Q11.** [2] What is the difference between source code and object code? *(E · 2.4)*

**Answer.** Source code is as written; object code is the same program in machine language.

**Q12.** [2] What is assembly language? Why is it called low-level? *(E · 2.4)*

**Answer.** Short codes for machine instructions, one for one; it is close to the machine and works on one kind of CPU.

**Q13.** [2] Give two advantages of high-level languages. *(E · 2.4)*

**Answer.** Easy to write and correct; work on many CPUs once translated.

**Q14.** [2] What does an assembler do? *(E · 2.4)*

**Answer.** Translates assembly language into machine code, one instruction for one.

**Q15.** [2] Why does a compiled program run faster than an interpreted one? *(E · 2.4)*

**Answer.** It is translated once, before running; an interpreter translates as it runs, every time.

**Q16.** [2] Why is an interpreter handy while learning? *(E · 2.4)*

**Answer.** You see each line's result at once, and the first error stops it where it is.

**Q17.** [2] What is an IDE? Name one. *(E · 2.4)*

**Answer.** Editor, translator and error messages in one window; IDLE.

**Q18.** [2] What is a software library? Name two Python libraries. *(E · 2.4)*

**Answer.** Ready-made tested code you can use; math, random.

**Q19.** [2] What do a linker and a loader do? *(E · 2.4)*

**Answer.** The linker joins library code into one executable file; the loader puts it into RAM to run.

**Q20.** [2] What is a process? How is it different from a program? *(E · 2.5)*

**Answer.** A program that is running; a program on storage is only a file.

**Q21.** [2] Explain process management with an example. *(E · 2.5)*

**Answer.** The OS gives each running program turns on the CPU: music, Maps and WhatsApp at once.

**Q22.** [2] Explain memory management. *(E · 2.5)*

**Answer.** The OS gives RAM to a program when it starts and takes it back when it ends.

**Q23.** [2] Explain file management. *(E · 2.5)*

**Answer.** Creating, naming, storing, finding, copying, deleting and protecting files in folders.

**Q24.** [2] How does the OS keep your phone secure? Two ways. *(E · 2.5)*

**Answer.** Screen lock or fingerprint; app permissions.

**Q25.** [2] Differentiate time sharing and space sharing. *(E · 2.5)*

**Answer.** One resource used in turns (CPU) vs one resource divided among programs (RAM).

**Q26.** [3] What happens when you tap an app icon? Name the functions used. *(M · 2.5)*

**Answer.** The OS finds it (file), gives memory and loads it (memory), gives CPU turns (process), shows its screen (device, UI).

**Q27.** [2] What is a user interface? Name its five kinds. *(E · 2.6)*

**Answer.** The way you give commands and see results: command, graphical, touch, voice, gesture.

**Q28.** [2] Give one advantage and one drawback of a CUI. *(E · 2.6)*

**Answer.** Uses little memory and is fast for experts; commands must be remembered.

**Q29.** [2] How do voice interfaces help people with disabilities? *(E · 2.6)*

**Answer.** People who cannot see or use their hands can give commands by speaking.

**Q30.** [3] What is the "digital arrest" fraud and what should you do? *(M · 2.5)*

**Answer.** A fake officer frightens a person on a video call into paying; hang up, tell family, report on 1930 or cybercrime.gov.in.
