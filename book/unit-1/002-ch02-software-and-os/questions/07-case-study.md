# Chapter 2: Software and Operating Systems: Case studies (8)

*Chapter 2 · Questions (online). Each case has three parts. Try each one first. The difficulty (E easy, M medium, H hard) and the section of the book are given in brackets. The answers of the generated pages come from checked tables in a program (`tools/ch02_typed_questions.py`).*

## Case studies

**Q1.** **Case: the new laptop.** Riya buys a laptop with Windows. (i) Which software came with it? (ii) She installs WhatsApp and a game: which group? (iii) Her old printer does not print: why? *(M · 2.1–2.6)*

**Answer.** (i) The OS, drivers and utilities. (ii) Application software. (iii) The printer's driver is missing; get it from the maker's site.

**Q2.** **Case: the slow phone.** Arjun's phone is slow and full. (i) Which utility helps? (ii) An app says "Clean now: 87% junk!". Should he install it? (iii) Which OS function closes apps when RAM is full? *(M · 2.1–2.6)*

**Answer.** (i) Disk cleanup (Storage, Files → Clean). (ii) No: such "cleaners" are often adware or trojans. (iii) Memory management.

**Q3.** **Case: the school app.** A school wants an app for fees and marks. (i) General-purpose or customised? (ii) Name one general-purpose program the office also uses. (iii) Why not buy a ready-made one? *(M · 2.1–2.6)*

**Answer.** (i) Customised. (ii) A spreadsheet. (iii) Its fee rules and report cards are its own.

**Q4.** **Case: the coding class.** Students write Python in IDLE. (i) What is IDLE? (ii) Which translator runs their programs? (iii) A program has an error in line 4: what do they see? *(M · 2.1–2.6)*

**Answer.** (i) An IDE. (ii) An interpreter (via bytecode). (iii) For a spelling error, Python stops before running anything; for a run-time error, lines 1–3 run and it stops at 4.

**Q5.** **Case: the game studio.** A studio writes a game in C++. (i) Which translator? (ii) Why does it run fast? (iii) Do players need the translator? *(M · 2.1–2.6)*

**Answer.** (i) A compiler. (ii) It is translated once into machine code. (iii) No: only the object (executable) file.

**Q6.** **Case: the busy airport.** (i) Which part is the OS? (ii) What do planes waiting for one runway show? (iii) A second runway opens: what is that in a phone? *(M · 2.1–2.6)*

**Answer.** (i) Air-traffic control. (ii) Programs taking turns on the CPU (process management). (iii) A second CPU core.

**Q7.** **Case: the video call.** A caller in a uniform says Dadi is under "digital arrest". (i) Is this real? (ii) What should the family do? (iii) Where should they report it? *(M · 2.1–2.6)*

**Answer.** (i) No: there is no such thing. (ii) Hang up; never pay or share OTPs. (iii) Chakshu on sancharsaathi.gov.in; if money was paid, 1930 and cybercrime.gov.in.

**Q8.** **Case: the accessible lab.** A student who cannot see joins the computer lab. (i) Which interface helps most? (ii) Name a software aid. (iii) Which chapter discusses this? *(M · 2.1–2.6)*

**Answer.** (i) Voice. (ii) A screen reader. (iii) Chapter 19 (technology and society).
