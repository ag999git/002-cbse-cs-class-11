## Fill in the blanks

**Q1.** Software that runs the computer itself is ______ software. *(E · 2.1)*

**Answer.** system.

**Q2.** The ______ is the most basic software: no other program runs without it. *(E · 2.2)*

**Answer.** operating system.

**Q3.** A ______ keeps a safe copy of your files. *(E · 2.2)*

**Answer.** backup utility.

**Q4.** A ______ makes files smaller. *(E · 2.2)*

**Answer.** compressor (compression utility).

**Q5.** A ______ lets the OS work one particular device. *(E · 2.2)*

**Answer.** device driver.

**Q6.** Harmful software is called ______. *(E · 2.2)*

**Answer.** malware.

**Q7.** Malware that forces ads on you is ______. *(E · 2.2)*

**Answer.** adware.

**Q8.** Ransomware locks your files and demands ______. *(E · 2.2)*

**Answer.** money.

**Q9.** Software made for one organisation is ______ software. *(E · 2.3)*

**Answer.** customised.

**Q10.** A word processor is ______ software. *(E · 2.3)*

**Answer.** general-purpose application.

**Q11.** IRCTC is an example of ______ software. *(E · 2.3)*

**Answer.** customised application.

**Q12.** Machine language uses only ______ and ______. *(E · 2.4)*

**Answer.** 0, 1.

**Q13.** Short codes such as ADD are used in ______ language. *(E · 2.4)*

**Answer.** assembly.

**Q14.** Python, C++ and Java are ______ languages. *(E · 2.4)*

**Answer.** high-level.

**Q15.** The translated program is called ______ code. *(E · 2.4)*

**Answer.** object.

**Q16.** A ______ translates the whole program at once. *(E · 2.4)*

**Answer.** compiler.

**Q17.** An ______ translates one statement at a time. *(E · 2.4)*

**Answer.** interpreter.

**Q18.** An ______ translates assembly into machine code. *(E · 2.4)*

**Answer.** assembler.

**Q19.** Python is translated by an ______. *(E · 2.4)*

**Answer.** interpreter.

**Q20.** IDLE is an ______ for Python. *(E · 2.4)*

**Answer.** IDE.

**Q21.** A running program is called a ______. *(E · 2.5)*

**Answer.** process.

**Q22.** Sharing the CPU in turns is ______ management. *(E · 2.5)*

**Answer.** process.

**Q23.** Creating, copying and deleting files is ______ management. *(E · 2.5)*

**Answer.** file.

**Q24.** Working the devices through their drivers is ______ management. *(E · 2.5)*

**Answer.** device.

**Q25.** Screen lock and app permissions belong to the OS function of ______. *(E · 2.5)*

**Answer.** security.

**Q26.** The OS is called a ______ manager. *(E · 2.5)*

**Answer.** resource.

**Q27.** CUI stands for ______ user interface. *(E · 2.6)*

**Answer.** character.

**Q28.** GUI stands for ______ user interface. *(E · 2.6)*

**Answer.** graphical.

**Q29.** "Hey Siri" uses a ______ interface. *(E · 2.6)*

**Answer.** voice.

**Q30.** Flipping the phone to silence it is a ______ interface. *(E · 2.6)*

**Answer.** gesture.
