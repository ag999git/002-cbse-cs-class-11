# Chapter 2: Software and Operating Systems: Long-answer questions (12)

*Chapter 2 · Questions (online). Four or five marks each. Try each one first. The difficulty (E easy, M medium, H hard) and the section of the book are given in brackets. The answers of the generated pages come from checked tables in a program (`tools/ch02_typed_questions.py`).*

## Long answers

**Q1.** [4] Explain the three groups of software with two examples each, and say why the OS is the most basic. *(M · 2.1–2.6)*

**Answer.** System (Windows, a printer driver); programming tools and translators (a compiler, IDLE); application (WhatsApp, IRCTC). The OS runs the hardware and gives every other program a place to run, so without it nothing works.

**Q2.** [5] Explain utility software. Describe four utilities and say where each is found on a phone or laptop. *(M · 2.1–2.6)*

**Answer.** Utilities keep the computer healthy. Compression (zip), backup (Google/WhatsApp backup), antivirus (Play Protect, Windows Security), disk cleanup (Storage, Files → Clean); the defragmenter only for hard disks.

**Q3.** [4] What is a device driver? Explain with the universal remote, and give the steps of installing a printer. *(M · 2.1–2.6)*

**Answer.** A program that lets the OS work one device. The remote works a TV only with its brand's codes. Steps: connect; OS notices; driver present? if not, download from the maker's site and install; test page.

**Q4.** [5] Explain machine, assembly and high-level languages with the self-driving car, and give one difference each. *(M · 2.1–2.6)*

**Answer.** High-level: one sentence ("take me to India Gate"); assembly: turn-by-turn steps, one code per instruction; machine: the exact signals (0s and 1s). High-level is easy and portable; low-level is hard and tied to one CPU.

**Q5.** [5] Differentiate between a compiler and an interpreter (five points), with the dubbed film and live commentary. *(M · 2.1–2.6)*

**Answer.** Whole program vs one statement; all errors listed vs stops at the first; object file vs none; faster vs slower; needed once vs every run. Dubbed once and shown many times vs translated live every match.

**Q6.** [4] A program has an error in line 3 and a division by 0 in line 6. What happens with a compiler and with an interpreter? *(M · 2.1–2.6)*

**Answer.** Compiler: reports line 3, runs nothing; after the fix, the file is made and runs until line 6 stops it. Interpreter: runs lines 1–2, stops at line 3; after the fix, runs up to line 6 and stops there.

**Q7.** [5] Explain the functions of an operating system with the airport. *(M · 2.1–2.6)*

**Answer.** Process (runway, planes in turn); memory (gates given and freed); file (records office); device (aerobridges, belts and their operators); security (security check). Plus the user interface (check-in counter).

**Q8.** [4] Explain the five kinds of user interface with "play my favourite song". *(M · 2.1–2.6)*

**Answer.** Type a command (CUI); click the song (GUI); tap it (touch); say "play my song" (voice); wave a hand (gesture).

**Q9.** [5] Describe the path from source code to a running program. *(M · 2.1–2.6)*

**Answer.** Editor → compiler (syntax errors fixed) → linker joins library code into an executable file → loader puts it into RAM → it runs; logical errors are found by testing.

**Q10.** [4] Explain the cyber links of the chapter: antivirus, backup, drivers, apps and permissions. *(M · 2.1–2.6)*

**Answer.** Antivirus catches viruses, trojans, adware; backup defeats ransomware; drivers only from the maker; apps only from the official store; refuse permissions an app does not need.

**Q11.** [4] Write about the "digital arrest" fraud: how it works, how it is traced, and how to report it. *(M · 2.1–2.6)*

**Answer.** Fake officer, fear, payment to mule accounts; traced through the bank trail, ATM CCTV, phone numbers and IP addresses; report on 1930, cybercrime.gov.in, Chakshu.

**Q12.** [4] Name the types of operating system with an example of each (beyond the syllabus). *(M · 2.1–2.6)*

**Answer.** Single-user (MS-DOS); multitasking (Windows); multi-user (a server); batch (overnight payslips); time-sharing (UNIX lab); real-time (airbag); multiprocessing (8-core phone); distributed (UPI systems); mobile (Android); embedded (washing machine).
