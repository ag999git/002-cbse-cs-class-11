# Chapter 1: Computer System Organisation: True or false (25)

*Chapter 1 · Questions (online). Every question is followed by its answer and the reason; for a false statement, the corrected statement is given. The section of the book is given in brackets after the difficulty (E easy, M medium, H hard).*

**Q1.** Information is raw data before processing. *(E · 1.1)*

**Answer.** False. *Why:* data is raw; information is data after processing.

**Q2.** Hardware without software can do no useful work. *(E · 1.2)*

**Answer.** True. *Why:* the hardware needs instructions; and software needs hardware to run on.

**Q3.** Firmware is software stored permanently inside a hardware chip. *(M · 1.2)*

**Answer.** True.

**Q4.** A monitor is an input device. *(E · 1.3)*

**Answer.** False. *Why:* it shows results, so it is an output device. (A touchscreen is both.)

**Q5.** A microphone is an input device. *(E · 1.3)*

**Answer.** True. *Why:* it sends sound into the computer.

**Q6.** A laser printer is an impact printer. *(E · 1.3)*

**Answer.** False. *Why:* it fuses toner onto the paper without striking it: non-impact.

**Q7.** A biometric reader identifies a person by a fingerprint, face or eye. *(E · 1.3)*

**Answer.** True.

**Q8.** A 3D printer is an output device. *(M · 1.3)*

**Answer.** True. *Why:* it builds a solid object from the computer's design: a result coming out.

**Q9.** The control unit does all the calculations. *(E · 1.4)*

**Answer.** False. *Why:* the ALU calculates; the control unit directs.

**Q10.** Registers are inside the CPU. *(E · 1.4)*

**Answer.** True.

**Q11.** The CPU takes in a whole program at once and runs all of it together. *(M · 1.4)*

**Answer.** False. *Why:* it handles one instruction at a time: fetch, decode, execute, then the next.

**Q12.** Data moves between the CPU and memory along buses. *(M · 1.5)*

**Answer.** True.

**Q13.** RAM is non-volatile. *(E · 1.6)*

**Answer.** False. *Why:* RAM is volatile; ROM is non-volatile.

**Q14.** ROM is secondary memory because it keeps its data without power. *(M · 1.6)*

**Answer.** False. *Why:* the CPU reads ROM directly, so it is primary memory. Keeping data without power does not make memory secondary.

**Q15.** The CPU runs programs straight from the hard disk. *(M · 1.6)*

**Answer.** False. *Why:* a program is first loaded into RAM; the CPU works only with primary memory.

**Q16.** Cache memory is faster than RAM. *(E · 1.6)*

**Answer.** True.

**Q17.** Cache memory is a kind of secondary memory. *(M · 1.6)*

**Answer.** False. *Why:* it sits between the CPU and RAM and is read directly by the CPU. (Some papers count it as primary memory.)

**Q18.** The farther a memory is from the CPU, the cheaper it is per byte. *(M · 1.6)*

**Answer.** True. *Why:* far memory is big, slow and cheap; near memory is small, fast and costly.

**Q19.** DRAM has to be refreshed many times a second. *(H · 1.6)*

**Answer.** True. *Why:* its tiny capacitors leak their charge; that is why it is called dynamic.

**Q20.** An SSD has a spinning platter. *(E · 1.6)*

**Answer.** False. *Why:* an SSD is made of flash chips; a hard disk (HDD) has spinning platters.

**Q21.** Reading a memory location removes its content. *(M · 1.6)*

**Answer.** False. *Why:* reading copies the content; only writing replaces it.

**Q22.** 1 KB = 1000 bytes in this syllabus. *(E · 1.7)*

**Answer.** False. *Why:* 1 KB = 1024 bytes (2¹⁰).

**Q23.** A nibble is half a byte. *(E · 1.7)*

**Answer.** True. *Why:* 4 bits = half of 8 bits.

**Q24.** 1 MB is bigger than 1000 KB. *(M · 1.7)*

**Answer.** True. *Why:* 1 MB = 1024 KB.

**Q25.** Mb and MB mean the same. *(H · 1.7)*

**Answer.** False. *Why:* small b means bits, capital B means bytes: 8 Mb = 1 MB.
