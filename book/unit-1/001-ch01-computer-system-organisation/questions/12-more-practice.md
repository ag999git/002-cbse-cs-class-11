## Exam Corner: model answers

**MCQ.** Which of these is volatile? (a) ROM (b) Hard disk (c) RAM (d) DVD [1]

Tags: MCQ · E · ★★★ · A

**Answer.** (c) RAM. *How to answer:* the letter **and** the name.

**Assertion–reason.** Assertion (A): RAM is called volatile memory. Reason (R): RAM needs power to keep its contents. (a) Both A and R are true and R is the correct explanation of A. (b) Both A and R are true but R is not the correct explanation of A. (c) A is true but R is false. (d) A is false but R is true. [1]

Tags: Assertion–reason · M · ★★★ · A

**Answer.** (a). *How to answer:* first decide A and R separately; then ask "does R explain **why** A is true?"

**Differentiate.** Differentiate between RAM and ROM. [2]

Tags: Differentiate · E · ★★ · A

**Answer.**

| RAM | ROM |
|---|---|
| Read and write memory | Read only memory |
| Volatile: contents lost when power is off | Non-volatile: contents stay |
| Holds programs and data in use | Holds start-up instructions |

*How to answer:* a table, with **matching** points on the same row (volatile against non-volatile). Two good rows are enough for 2 marks.

**Calculate.** Convert 3 GB into KB. [2]

Tags: Calculate · M · ★★★ · A

**Answer.** 3 GB = 3 × 1024 MB = 3072 MB = 3072 × 1024 KB = 3 145 728 KB. *How to answer:* show each step with its unit.

**Draw.** Draw the block diagram of a computer and write the task of each unit. [3]

Tags: Draw · M · ★ · B

**Answer.** The block diagram of section 1.5, with one line on each unit (the table of functional units). *How to answer:* boxes labelled, solid arrows for data, dashed arrows for control, then one line per unit.

## More objective questions

**4.** Which memory is refreshed thousands of times a second? (a) SRAM (b) DRAM (c) PROM (d) flash

**Answer.** (b) DRAM. *Why:* its tiny charges leak away unless they are topped up.

**5.** Which ROM is erased by ultraviolet light? (a) PROM (b) EPROM (c) EEPROM (d) mask ROM

**Answer.** (b) EPROM. *Why:* it has a small window for the ultraviolet light.

**7.** Which part of the CPU decides what happens next? (a) ALU (b) control unit (c) register (d) cache

**Answer.** (b) control unit. *Why:* it fetches and decodes each instruction and directs the others.

**9.** OMR sheets are used for: (a) cheques (b) MCQ answer sheets (c) fingerprints (d) barcodes

**Answer.** (b) MCQ answer sheets. *Why:* OMR reads pencil marks in printed bubbles.

**11.** A printer that can make carbon copies is: (a) laser (b) inkjet (c) dot-matrix (d) 3D printer

**Answer.** (c) dot-matrix. *Why:* only an impact printer strikes through to the copy.

**12.** When the CPU finds the data it needs in the cache, it is called: (a) a cache miss (b) a cache hit (c) booting (d) a fetch error

**Answer.** (b) a cache hit.

**15.** Printed output on paper is called ______ copy.

**Answer.** hard.

**19.** A ______ printer builds an object layer by layer.

**Answer.** 3D.

**20.** The rings on a hard-disk platter are called ______.

**Answer.** tracks.

**21.** The ALU does arithmetic and ______ operations.

**Answer.** logic (comparisons).

**22.** Colour printers use the inks cyan, magenta, yellow and ______.

**Answer.** black.

**26.** Reading a memory box changes its content.

**Answer.** False. *Why:* reading only copies; writing replaces.

**28.** 1 KB = 1000 bytes in CBSE answers.

**Answer.** False. *Why:* use 1024.

**30.** A Braille display is an output device.

**Answer.** True. *Why:* it shows text as pins that you feel.

**31.** Flash memory is a kind of EEPROM.

**Answer.** True. *Why:* it is erased electrically, in blocks.

**36.** A: A touchscreen is an output device only. R: A touchscreen shows pictures.

**Answer.** (d). *Why:* A is false (it is both); R is true.

## Traps: true or false?

| Statement | True or false | Why |
|---|:-:|---|
| Secondary memory is directly accessed by the CPU | **False** | Data goes into RAM first |
| Cache memory is faster than RAM | **True** | That is why it is used |
| ROM holds the start-up instructions | **True** | Read first when the computer is switched on |
| An SSD has moving parts | **False** | It uses flash chips; an HDD has moving parts |
| A touchscreen is both an input and an output device | **True** | It senses touch and shows pictures |
| 1 TB = 1024 GB | **True** | Each step is 1024 |

## More questions with answers

**Q1.** Which of these is **not** an input device? (a) Scanner (b) Microphone (c) Speaker (d) Webcam [1]

Tags: MCQ · E · ★ · B · Based on: DoE Delhi 2025–26

**Answer.** (c) Speaker. *Why:* a speaker turns data **into** sound for you; the data flows **out**. The other three send data in. *Exam tip:* ask "which way does the data flow?" for every option.

**Q2.** The ALU is a part of: (a) the input unit (b) the output unit (c) the CPU (d) RAM [1]

Tags: MCQ · E · ★ · B · Based on: DoE Delhi 2025–26

**Answer.** (c) the CPU. *Why:* the CPU = control unit + ALU + registers. RAM is separate memory, outside the CPU.

**Q11.** Which part of the CPU controls the flow of data between the units? [1]

Tags: Name · E · ★ · B · Based on: DoE Delhi 2025–26

**Answer.** The control unit. *Why:* it directs every unit (the head chef); the ALU only calculates and compares.

**Q15.** Give the full forms of CPU and ALU. [1]

Tags: Expand · E · ★ · B

**Answer.** CPU: Central Processing Unit. ALU: Arithmetic Logic Unit. *Exam tip:* write every word of the full form; "Arithmetic Logic Unit" is the standard form.

**Q22.** What is cache memory? Why is it used? [2]

Tags: Define · M · ★ · B

**Answer.** Cache is a small, very fast memory between the CPU and RAM that keeps copies of the data and instructions the CPU uses most often. It is used because the CPU is far faster than RAM: with the most-used items close at hand, the CPU waits less and the computer runs faster. *Why it works:* the masala dabba on the counter saves a walk to the shelf for every pinch of salt.

**Q23.** Name the two main parts of the CPU and write one job of each. [2]

Tags: Explain · E · ★ · B

**Answer.** Control unit: fetches and decodes each instruction and directs the other units. ALU: does arithmetic (+ − × ÷) and logic (comparisons). *Exam tip:* registers are the third part; mention them in one line if the question says "parts" without "two".

**Q24.** Classify as input, output, or both: touchscreen, plotter, barcode reader, projector. [2]

Tags: Classify · E · ★ · B

**Answer.** Touchscreen: both. Plotter: output. Barcode reader: input. Projector: output. *Why:* a touchscreen senses touch (in) and shows pictures (out); a plotter and a projector send results out; a barcode reader sends a code in.

**Q25.** Draw the block diagram of a computer system and briefly explain its functional units. [3]

Tags: Draw · M · ★ · B · Based on: KVS Silchar

**Answer.** Draw the block diagram of section 1.5 and write one line for each unit from the table of functional units: input unit, CPU (control unit, ALU, registers), primary memory, secondary memory, output unit. *Exam tip:* label every box; solid arrows for data, dashed arrows for control signals.

**Q28.** Expand OMR, MICR and OCR, and give one use of each. [3]

Tags: Expand · E · ★ · B

**Answer.** OMR: Optical Mark Reader, checks MCQ answer sheets. MICR: Magnetic Ink Character Reader, reads the numbers on bank cheques. OCR: Optical Character Recognition, turns printed text in a picture into text you can edit. *Exam tip:* one use each is enough; write the full form first.

**Q29.** Differentiate between impact and non-impact printers (two points). [2]

Tags: Differentiate · E · ★ · B

**Answer.**

| Basis of difference | Impact printer | Non-impact printer |
|---|---|---|
| How it prints | Strikes an inked ribbon against the paper | No contact: ink sprayed or fixed by laser |
| Noise | Noisy | Quiet |

*Why these two:* they follow from how each printer works. *Exam tip:* a third row (carbon copies possible / not possible) is good insurance.

**Q30.** What is a memory address? How is it different from the content of a memory location? [2]

Tags: Define · M · ☆ · B

**Answer.** A memory address is the number that identifies one location (box) of memory; the content is the data stored in that location. The address stays the same while the content can change. *Why:* like a house number and the people who live in the house.

**Q31.** Why is primary memory called "non-destructive read" and "destructive write" memory? [2]

Tags: Explain · M · ☆ · B

**Answer.** Reading a memory location copies its content without changing it (non-destructive read). Writing puts new content into the location, and the old content is lost (destructive write). *Exam tip:* explain both halves; each carries one mark.

**Q32.** Name the type of ROM in each case: (i) written once by the user (ii) erased by ultraviolet light (iii) erased electrically, byte by byte (iv) written when the chip is made. [2]

Tags: Name · M · ★ · B

**Answer.** (i) PROM (ii) EPROM (iii) EEPROM (iv) mask ROM. *Why:* the letters say it: P programmable, E erasable, EE electrically erasable.

**Q33.** Differentiate between SRAM and DRAM (two points). [2]

Tags: Differentiate · M · ★ · B

**Answer.**

| Basis of difference | SRAM | DRAM |
|---|---|---|
| Refreshing | Not needed | Refreshed thousands of times a second |
| Speed and cost | Faster, costlier | Slower, cheaper |
| Used for | Cache | Main memory |

*Why:* DRAM stores each bit as a leaking charge; SRAM as a small switch circuit.

**Q34.** What is a cache hit? What is a cache miss? [2]

Tags: Define · M · ☆ · B

**Answer.** A cache hit: the data the CPU needs is found in the cache. A cache miss: it is not there, so it must be fetched from RAM, which is slower. *Why it matters:* the more hits, the faster the computer.

**Q35.** What is the Von Neumann architecture? [2]

Tags: Define · M · ☆ · B

**Answer.** The plan of a computer in which a CPU works with one memory that holds both the program and its data, with input and output units; described by John von Neumann in 1945. Almost all computers follow it. *Exam tip:* "program and data in the same memory" is the key phrase.

**Q36.** What is a bus? Name its three parts. [2]

Tags: Define · M · ★ · B

**Answer.** A bus is a set of wires that carries signals between the units of a computer. Its three parts: the data bus (carries data), the address bus (carries the address of the memory location), the control bus (carries control signals such as read and write).

**Q37.** Classify each as input, output, both or storage: Braille keyboard, smart card reader, plotter, memory card, headset with microphone, light pen. [3]

Tags: Classify · E · ★ · B

**Answer.** Braille keyboard: input. Smart card reader: input. Plotter: output. Memory card: storage. Headset with microphone: both. Light pen: input. *Why:* ask which way the data flows; a memory card keeps data, so it is storage, not input or output.

**Q38.** Arrange in ascending order of capacity: 1 TB, 2048 GB, 500 MB, 1 PB. [2]

Tags: Arrange · M · ★★★ · A

**Answer.** 500 MB < 1 TB < 2048 GB < 1 PB. *Why:* 2048 GB = 2 TB, and 1 PB = 1024 TB. *Exam tip:* change everything to one unit first.

**Q39.** How many bytes are there in 4 MB? Show the steps. [2]

Tags: Calculate · M · ★★★ · A

**Answer.** 4 MB = 4 × 1024 KB = 4096 KB = 4096 × 1024 bytes = **4 194 304 bytes**. *Why:* MB → KB → bytes is two steps down: multiply by 1024 twice.

**Q40.** A file of 24 576 bits is to be stored. What is its size in KB? [2]

Tags: Calculate · M · ★★ · A

**Answer.** 24 576 bits ÷ 8 = 3072 bytes; 3072 ÷ 1024 = **3 KB**. *Why:* bits → bytes divide by 8; bytes → KB divide by 1024.

**Q41.** Why does a computer need both RAM and cache, when both are volatile? [2]

Tags: Explain · M · ★ · B

**Answer.** RAM is big enough to hold the programs and data in use, but slow compared with the CPU. Cache is very fast but small and costly. Keeping the most-used items in cache lets the CPU wait less, while RAM holds everything else. *Why it works:* the masala dabba and the shelf.

**Q42.** What happens, step by step, when you press a key in a word processor? [3]

Tags: Explain · M · ☆ · B

**Answer.** (1) The keyboard sends the key's code to the CPU. (2) The CPU stores the letter in RAM with the document. (3) The word-processor program in RAM tells the CPU what to do with it. (4) The CPU sends the new screen picture to the monitor. (5) The document is copied to secondary memory only when it is saved. *Exam tip:* name the unit in each step.

**Q43.** Give two differences between an HDD and an SSD, and one reason why laptops now use SSDs. [3]

Tags: Differentiate · M · ★ · B

**Answer.** HDD: magnetic platters that spin, with a moving arm; SSD: flash chips, no moving parts. HDD: slower; SSD: faster. Laptops use SSDs because they are faster, stronger when the laptop is carried or dropped, quieter and use less power.

**Q44.** Case study: a school uses OMR sheets for its unit tests, a biometric reader for attendance and a laser printer for report cards. (i) Which of these are input devices? (ii) Which is an impact or non-impact printer? (iii) Why is OMR faster than checking by hand? (iv) Where are the scanned attendance records kept for next year? [4]

Tags: Case study · M · ☆ · B

**Answer.** (i) The OMR and the biometric reader. (ii) The laser printer is non-impact. (iii) The OMR reads hundreds of sheets a minute and makes no counting mistakes. (iv) In secondary memory (a hard disk, an SSD or cloud storage), because it keeps data permanently.

**Q45.** Explain the memory hierarchy with a labelled diagram, and give one reason why a computer does not use only the fastest memory. [3]

Tags: Draw · M · ★ · B

**Answer.** Draw the pyramid of section 1.6: registers at the top, then cache, primary memory (RAM, ROM), secondary memory at the base; arrows showing "faster, costlier, closer to the CPU" upwards and "bigger, slower, cheaper" downwards. Reason: the fastest memory costs far more per byte, so a computer with only fast memory would be unaffordable. *Exam tip:* label all four levels with an example each.

## Worked example (units): arrange in ascending order: 4096 KB, 3 MB, 0.5 GB, 600 MB

> **Worked example 2: arrange in ascending order: 4096 KB, 3 MB, 0.5 GB, 600 MB**
>
> Change all to one unit, MB: 4096 KB = 4096 ÷ 1024 = 4 MB; 0.5 GB = 0.5 × 1024 = 512 MB.
>
> So: 3 MB, 4 MB, 512 MB, 600 MB, that is **3 MB < 4096 KB < 0.5 GB < 600 MB**.

## Worked example (units): how many 4 MB photos fit on a 2 GB pen drive?

> **Worked example 3: how many 4 MB photos fit on a 2 GB pen drive?**
>
> 2 GB = 2 × 1024 MB = 2048 MB. Photos: 2048 ÷ 4 = **512 photos**.

## Chapter 1 on one card

> **Chapter 1 on one card**
>
> - **System:** input → process → output + storage · data → information · instruction → program
> - **Hardware / software:** touch / cannot touch · stove / recipe · each needs the other
> - **Devices:** which way does the data flow? In = input, out = output, both = touchscreen · pen drive = storage
> - **CPU:** CU directs · ALU calculates and compares · registers hold the now · fetch → decode → execute
> - **Memory:** registers → cache → RAM/ROM → secondary: farther = bigger, slower, cheaper
> - **RAM vs ROM:** read-write, volatile, programs in use · read-only, non-volatile, start-up
> - **Secondary:** permanent, via RAM · HDD magnetic, moving · SSD flash, none · DVD optical
> - **Units:** 4 bits nibble · 8 bits byte · × 1024: KB, MB, GB, TB, PB · big → small multiply
