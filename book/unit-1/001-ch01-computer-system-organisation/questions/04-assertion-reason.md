# Chapter 1: Computer System Organisation: Assertion and reason (15)

*Chapter 1 · Questions (online). Every question is followed by its answer and the reason. The section of the book is given in brackets after the difficulty (E easy, M medium, H hard).*

**Choose for every question:**

- (a) Both A and R are true, and R is the correct explanation of A.
- (b) Both A and R are true, but R is not the correct explanation of A.
- (c) A is true, but R is false.
- (d) A is false, but R is true.

**Q1.** **A:** Unsaved work is lost when the power goes off. **R:** RAM is volatile. *(E · 1.6)*

**Answer.** (a). *Why:* unsaved work is only in RAM, and RAM needs power to hold it.

**Q2.** **A:** ROM holds the start-up instructions. **R:** ROM is non-volatile. *(E · 1.6)*

**Answer.** (a). *Why:* the start-up program must be there every time the power comes on, so it needs a memory that keeps its contents.

**Q3.** **A:** ROM is secondary memory. **R:** ROM keeps its contents without power. *(M · 1.6)*

**Answer.** (d). *Why:* R is true, but ROM is primary memory: the CPU reads it directly.

**Q4.** **A:** Cache memory makes a computer faster. **R:** Cache keeps copies of the data the CPU uses most often. *(E · 1.6)*

**Answer.** (a). *Why:* the CPU finds most of what it needs in the fast cache and waits less for RAM.

**Q5.** **A:** A computer needs secondary memory. **R:** Secondary memory is faster than RAM. *(M · 1.6)*

**Answer.** (c). *Why:* A is true (RAM is volatile and small, so files must be kept elsewhere), but secondary memory is slower than RAM.

**Q6.** **A:** A touchscreen is both an input and an output device. **R:** It shows output and takes the user's touch as input. *(E · 1.3)*

**Answer.** (a).

**Q7.** **A:** A dot-matrix printer is noisy. **R:** It is a non-impact printer. *(M · 1.3)*

**Answer.** (c). *Why:* it is noisy because it is an **impact** printer: its pins strike the ribbon.

**Q8.** **A:** The ALU decides which instruction runs next. **R:** The ALU carries out calculations and comparisons. *(M · 1.4)*

**Answer.** (d). *Why:* the control unit decides what happens next; R is true.

**Q9.** **A:** Registers are the fastest memory. **R:** Registers are inside the CPU. *(E · 1.4, 1.6)*

**Answer.** (a). *Why:* nothing is closer to the work than the plate in the cook's hand.

**Q10.** **A:** An SSD is quieter than a hard disk. **R:** An SSD has no moving parts. *(E · 1.6)*

**Answer.** (a).

**Q11.** **A:** DRAM is used for main memory. **R:** DRAM is faster than SRAM. *(H · 1.6)*

**Answer.** (c). *Why:* DRAM is used because it is cheaper per byte; SRAM is the faster one.

**Q12.** **A:** 1 KB is 1024 bytes. **R:** Memory units go in powers of 2. *(M · 1.7)*

**Answer.** (a). *Why:* 1024 = 2¹⁰.

**Q13.** **A:** 4096 KB is greater than 3 MB. **R:** 4096 is greater than 3. *(H · 1.7)*

**Answer.** (b). *Why:* A is true (4096 KB = 4 MB), but comparing the bare numbers is not the reason: different units cannot be compared directly.

**Q14.** **A:** Software does not wear out. **R:** Software has no physical parts. *(M · 1.2)*

**Answer.** (a).

**Q15.** **A:** A pen drive is an input device. **R:** Data can be copied from a pen drive into the computer. *(H · 1.3)*

**Answer.** (d). *Why:* a pen drive is a storage device; R is true, but copying data does not make it an input device.
