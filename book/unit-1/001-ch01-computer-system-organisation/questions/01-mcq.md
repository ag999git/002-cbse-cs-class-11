# Chapter 1: Computer System Organisation: Multiple-choice questions (40)

*Chapter 1 · Questions (online). Every question is followed by its answer and the reason, as in the printed book. Try each one first. The section of the book is given in brackets after the difficulty (E easy, M medium, H hard).*

## Data, hardware and software (1.1, 1.2)

**Q1.** Which of these is data, not information? *(E · 1.1)*
(a) The class average is 71.5 (b) 67, 82, 45, 90 (c) The hottest day of the week was Monday (d) Seats still free: 12

**Answer.** (b) 67, 82, 45, 90. *Why:* these are raw figures with nothing done to them. The others are results of processing.

**Q2.** A set of instructions, in order, that does a whole job is called *(E · 1.1)*
(a) data (b) an instruction (c) a program (d) information

**Answer.** (c) a program. *Why:* one instruction is one command; a program is many instructions in order.

**Q3.** Which of these is software? *(E · 1.2)*
(a) Keyboard (b) WhatsApp (c) Motherboard (d) Hard disk

**Answer.** (b) WhatsApp. *Why:* you cannot touch it; it is a program. The others are physical parts.

**Q4.** Software stored permanently inside a hardware chip is called *(M · 1.2)*
(a) shareware (b) firmware (c) freeware (d) malware

**Answer.** (b) firmware. *Why:* "firm" because it sits between hard (fixed) and soft (easy to change); the start-up program in ROM is firmware.

**Q5.** Which statement is true? *(E · 1.2)*
(a) Hardware wears out; software does not wear out (b) Software can be touched (c) Hardware is changed by editing (d) Software is replaced with a screwdriver

**Answer.** (a). *Why:* parts wear out with use; a program does not wear out, though it can have errors (bugs).

## Input and output devices (1.3)

**Q6.** Which of these is **not** an input device? *(E · 1.3)*
(a) Scanner (b) Microphone (c) Plotter (d) Light pen

**Answer.** (c) Plotter. *Why:* a plotter draws on paper: it takes results out, so it is an output device.

**Q7.** The device that reads the numbers printed at the bottom of a bank cheque is *(E · 1.3)*
(a) OMR (b) OCR (c) MICR (d) barcode reader

**Answer.** (c) MICR. *Why:* the numbers are printed in magnetic ink; MICR = Magnetic Ink Character Reader.

**Q8.** Answer sheets with bubbles filled in pencil are read by *(E · 1.3)*
(a) OMR (b) MICR (c) OCR (d) webcam

**Answer.** (a) OMR. *Why:* Optical Mark Reader: it reads marks (filled bubbles), not letters.

**Q9.** A photo of a printed page is turned into text that can be edited by *(M · 1.3)*
(a) OMR (b) OCR (c) MICR (d) a plotter

**Answer.** (b) OCR. *Why:* Optical Character Recognition recognises letters (characters) in a picture.

**Q10.** Which device is both an input and an output device? *(E · 1.3)*
(a) Monitor (b) Touchscreen (c) Keyboard (d) Speaker

**Answer.** (b) Touchscreen. *Why:* it shows output and takes your touch as input. A plain monitor only shows output.

**Q11.** Which of these is a non-impact printer? *(E · 1.3)*
(a) Dot-matrix printer (b) Laser printer (c) Line printer (d) Daisy-wheel printer

**Answer.** (b) Laser printer. *Why:* it does not strike the paper; the others hit an inked ribbon against the paper.

**Q12.** Output printed on paper is called *(E · 1.3)*
(a) soft copy (b) hard copy (c) firmware (d) a peripheral

**Answer.** (b) hard copy. *Why:* you can hold it; a soft copy is what you see on a screen.

**Q13.** A pen drive is best described as *(M · 1.3, 1.6)*
(a) an input device (b) an output device (c) a storage device (d) a processing device

**Answer.** (c) a storage device. *Why:* it keeps data for later. Storage devices are kept apart from input and output devices in this book (and in most answer keys).

**Q14.** Which device helps a person who cannot see to read text on a computer? *(M · 1.3)*
(a) Braille display (b) Plotter (c) Projector (d) OMR

**Answer.** (a) Braille display. *Why:* it raises small pins that the fingers read as Braille dots.

**Q15.** Which of these is used at a shop billing counter to read a product's code? *(E · 1.3)*
(a) MICR (b) Barcode reader (c) Plotter (d) Webcam

**Answer.** (b) Barcode reader. *Why:* the bars stand for a code that the reader sends to the computer.

## The CPU and the block diagram (1.4, 1.5)

**Q16.** Which part of the CPU compares two numbers? *(E · 1.4)*
(a) Control unit (b) ALU (c) Register (d) Cache

**Answer.** (b) ALU. *Why:* the Arithmetic **Logic** Unit calculates and compares (logic = comparisons such as 7 > 5).

**Q17.** Which part of the CPU directs all the other parts? *(E · 1.4)*
(a) ALU (b) Control unit (c) RAM (d) Hard disk

**Answer.** (b) Control unit. *Why:* like the head chef, it reads each instruction and tells every part what to do and when.

**Q18.** The fastest memory in a computer is *(E · 1.4, 1.6)*
(a) cache (b) RAM (c) registers (d) SSD

**Answer.** (c) registers. *Why:* they are inside the CPU itself, the plate in the cook's hand.

**Q19.** The correct order of the CPU's cycle is *(M · 1.4)*
(a) decode, fetch, execute (b) fetch, execute, decode (c) fetch, decode, execute (d) execute, fetch, decode

**Answer.** (c) fetch, decode, execute. *Why:* first bring the instruction from memory, then work out what it means, then do it.

**Q20.** The CPU chip is fitted on the *(E · 1.4)*
(a) hard disk (b) motherboard (c) monitor (d) power supply

**Answer.** (b) motherboard. *Why:* the main circuit board; every part connects to it.

**Q21.** In the block diagram, the arrow from the CPU goes to the output unit, and the arrow into the CPU comes from the *(E · 1.5)*
(a) input unit (b) printer (c) monitor (d) speaker

**Answer.** (a) input unit. *Why:* data goes in, is processed, and comes out.

**Q22.** The sets of wires that carry data, addresses and control signals between units are called *(M · 1.5)*
(a) registers (b) buses (c) ports (d) tracks

**Answer.** (b) buses. *Why:* like a bus route, they carry many things along the same path.

**Q23.** In the Von Neumann plan of a computer *(H · 1.5)*
(a) programs and data are kept in separate memories (b) one memory holds both the program and its data (c) there is no memory (d) the ALU stores the program

**Answer.** (b). *Why:* this is the idea of the stored program: the program is kept in memory like data.

## Memory (1.6)

**Q24.** Which memory loses its contents when the power goes off? *(E · 1.6)*
(a) ROM (b) RAM (c) Hard disk (d) SSD

**Answer.** (b) RAM. *Why:* RAM is volatile; it needs power to hold its contents.

**Q25.** The start-up instructions of a computer are stored in *(E · 1.6)*
(a) RAM (b) cache (c) ROM (d) registers

**Answer.** (c) ROM. *Why:* they must survive power cuts, and ROM is non-volatile.

**Q26.** Which of these is primary memory? *(M · 1.6)*
(a) Pen drive (b) Hard disk (c) ROM (d) Blu-ray disc

**Answer.** (c) ROM. *Why:* the CPU reads ROM directly; the others are secondary memory.

**Q27.** Cache memory sits between *(E · 1.6)*
(a) RAM and the hard disk (b) the CPU and RAM (c) the keyboard and the CPU (d) ROM and the printer

**Answer.** (b) the CPU and RAM. *Why:* it keeps copies of what the CPU uses most, so the CPU waits less for RAM.

**Q28.** Cache is usually made of *(H · 1.6)*
(a) DRAM (b) SRAM (c) EPROM (d) flash

**Answer.** (b) SRAM. *Why:* static RAM is faster (no refreshing), though costlier, which suits a small, fast memory.

**Q29.** Main memory (RAM) in a computer is usually made of *(M · 1.6)*
(a) SRAM (b) DRAM (c) PROM (d) magnetic tape

**Answer.** (b) DRAM. *Why:* dynamic RAM is cheaper per byte, so a large amount can be fitted.

**Q30.** A ROM chip that is erased with ultraviolet light is *(M · 1.6)*
(a) PROM (b) EPROM (c) EEPROM (d) DRAM

**Answer.** (b) EPROM. *Why:* erasable PROM has a small window through which UV light erases it; EEPROM is erased electrically.

**Q31.** Which memory is non-volatile? *(E · 1.6)*
(a) DRAM (b) SRAM (c) Flash memory (d) Cache

**Answer.** (c) Flash memory. *Why:* pen drives and SSDs keep data without power. The other three are kinds of RAM.

**Q32.** Arrange from fastest to slowest: registers, RAM, hard disk, cache *(M · 1.6)*
(a) registers, cache, RAM, hard disk (b) cache, registers, RAM, hard disk (c) RAM, cache, registers, hard disk (d) registers, RAM, cache, hard disk

**Answer.** (a). *Why:* the farther from the CPU, the slower (and bigger and cheaper).

**Q33.** The number of one memory location is called its *(E · 1.6)*
(a) content (b) address (c) sector (d) byte

**Answer.** (b) address. *Why:* like a house number; the content is what is kept in the box.

**Q34.** The ring on a disk platter on which data is recorded is a *(M · 1.6)*
(a) sector (b) track (c) cluster (d) bus

**Answer.** (b) track. *Why:* a sector is a slice of a track.

**Q35.** Which of these has no moving parts? *(E · 1.6)*
(a) Hard disk (b) SSD (c) DVD drive (d) Magnetic tape drive

**Answer.** (b) SSD. *Why:* it is made of flash chips; the others spin or wind.

## Units of memory (1.7)

**Q36.** 1 nibble = *(E · 1.7)*
(a) 2 bits (b) 4 bits (c) 8 bits (d) 16 bits

**Answer.** (b) 4 bits. *Why:* half a byte (a "nibble" is a small bite).

**Q37.** 1 GB = *(E · 1.7)*
(a) 1000 MB (b) 1024 KB (c) 1024 MB (d) 1024 TB

**Answer.** (c) 1024 MB. *Why:* every unit from KB to PB is 1024 times the one before.

**Q38.** The largest of these is *(M · 1.7)*
(a) 2048 MB (b) 1 GB (c) 3 000 000 KB (d) 1.5 GB

**Answer.** (c) 3 000 000 KB. *Why:* in MB: 2048, 1024, about 2930, 1536.

**Q39.** How many bits are there in 2 KB? *(M · 1.7)*
(a) 2048 (b) 16 000 (c) 16 384 (d) 8192

**Answer.** (c) 16 384. *Why:* 2 × 1024 = 2048 bytes; × 8 = 16 384 bits.

**Q40.** Which unit comes just after TB? *(E · 1.7)*
(a) GB (b) PB (c) MB (d) KB

**Answer.** (b) PB. *Why:* bit, nibble, byte, KB, MB, GB, TB, PB.
