# Word size, buses and Mbps

**Sometimes asked** · asked in a few school papers, not named in the CBSE syllabus · Chapter 1, section 1.4

## Word size

The **word size** of a CPU is the number of bits it can handle in one step. Most computers and phones today are
**64-bit**: they work on 64 bits at a time. Older computers were 32-bit.

*In the kitchen:* the size of the cook's plate. A bigger plate holds more in one go.

## Buses

A **bus** is a set of wires that carries signals between the CPU, memory and the other units, like a road with many
lanes.

| Bus | Carries | Direction |
|---|---|---|
| **Data bus** | The data itself | Both ways (CPU ↔ memory) |
| **Address bus** | The address: which memory location to use | One way (CPU → memory) |
| **Control bus** | Control signals such as "read" and "write" | Both ways |

## Mbps and MBps

- **Mbps** = mega**bits** per second (small b): used for internet speeds.
- **MBps** = mega**bytes** per second (capital B): used for file copying.
- 8 bits = 1 byte, so **divide Mbps by 8 to get MBps**: an 80 Mbps connection copies at about 10 MB per second.

## Questions

**Q.** What is meant by the word size of a computer?
**Answer.** The number of bits the CPU can process in one operation, for example 64 bits.

**Q.** Name the three buses that connect the CPU to memory.
**Answer.** Data bus (carries data), address bus (carries the memory address), control bus (carries control signals
such as read and write).

**Q.** A connection is 80 Mbps. What is that in MBps?
**Answer.** 80 ÷ 8 = 10 MBps.
