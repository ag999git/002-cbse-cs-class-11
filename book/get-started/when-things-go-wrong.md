## While writing programs

- Line numbers or `>>>` copied into a script → delete them; copy code from this website or the notebooks, not from a book page.
- `IndentationError` after pasting code → delete the spaces at the start of the line.
- A file saved as `hello.py.txt` → save from IDLE or VS Code, not Notepad; in File Explorer, View → show **File name extensions**.
- Reading any error message: Chapter 6's page [Reading an error message](../unit-2/006-ch06-getting-started-with-python/explained-reading-an-error-message.md).
